Device Settings

Display Calibration

Calibrate the visible display area. The margins define the safe zone where content won't be cut off by the frame or bezel.

The calibration pattern shows a checkerboard border at screen edges, a black rectangle at current margins, and tick marks for measurement. Adjust margins until the black rectangle is fully visible.

Scene Schedule

Configure which scenes display at specific times within each hour. Each hour can have multiple time slots with different scenes.

GitHub Pages Web UI Password

Set a password for the GitHub Pages web UI (MQTT-based interface). This password is used to generate HMAC signatures for secure authentication. The password is never transmitted - only HMAC signatures are sent.

Configuration Backup & Restore

Export or import device configuration. Backup is encrypted with your Web UI password and includes WiFi credentials, schedule, media settings, and allowed phone numbers.
